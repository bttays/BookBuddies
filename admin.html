This app stores its data in a Google Sheet through a small free backend. Connect it once below.

First-time setup

  1. Create a new Google Sheet at sheets.google.com.
  2. Go to Extensions → Apps Script and paste in the provided Code.gs file.
  3. Deploy → New deployment → Web app. Execute as Me, access Anyone.
  4. Copy the URL ending in /exec and paste it above, then tap Connect.

Full written steps are in SETUP.md.
